Setting up PostgreSQL AWS
Buat VM untuk PostgreSQL
Launch Instance

Name: db-postgres-instance

AMI: Ubuntu 22.04 (atau Amazon Linux)

Instance type: t2.micro ✅ (free tier)

Key pair: Buat atau pilih key (untuk SSH)

Allow SSH (port 22)

Tambahkan Rule:

Custom TCP Rule → Port 5432 (PostgreSQL)

Source: Custom IP or 0.0.0.0/0 (untuk testing)

Launch and wait...

Cara Tambahkan Rule Port 5432 (PostgreSQL):
Di bagian “Network settings”, pastikan:

“Create security group” ✅ dipilih.

Lalu klik tombol Edit (di kanan atas bagian “Network settings”).

Di dalam form yang muncul:

Scroll ke bagian "Firewall (security group rules)"

Klik "Add security group rule"

Atur rule seperti ini:

Field	Value
Type	Custom TCP Rule
Protocol	TCP
Port Range	5432
Source	0.0.0.0/0 (atau IP kamu)
Description (optional)	PostgreSQL Access

⚠️ Jika ini hanya untuk testing, 0.0.0.0/0 boleh. Tapi untuk production, sebaiknya pakai IP spesifik (misalnya IP dari server aplikasimu atau IP publik lokal).
